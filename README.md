## 📖 About the Game

This is a text-based implementation of the classic **Rock, Paper, Scissors** game, built entirely in Python. It adds a competitive twist: instead of a single round, players compete until one reaches **10 points**.

The game features real-time score tracking, descriptive commentary for each round, and robust input validation — making it both fun and reliable.

---

## ✨ Key Features

- 🎮 **First to 10 Wins** — Competitive scoring system that keeps the game engaging.
- 📊 **Live Score Tracking** — See your score and the computer's after every round.
- 💬 **Descriptive Round Messages** — Clear feedback (e.g., *"Rock smashes scissors! You scored 1 point."*).
- 🛡️ **Input Validation** — Handles invalid input gracefully without crashing.
- 🚪 **Quit Anytime** — Type `quitgame` to exit the match cleanly.
- 🎲 **Random Computer Choice** — Powered by Python's built-in `random` module.

---

## 🎮 How to Play

1. Run the script in any Python environment.
2. When prompted, enter one of:
   - `rock`
   - `paper`
   - `scissors`
3. The computer will randomly choose its move.
4. The winner of each round gets **1 point**.
5. The first player to reach **10 points** wins the match.
6. To quit at any time, type `quitgame`.
